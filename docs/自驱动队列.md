# 自驱动队列（M4 剩余 4 项 + M5 全部 12 项）

状态：`todo` / `doing` / `done` / `blocked`。
每完成一项**立即**回填本表（commit、门禁、push），它是中断后恢复的唯一入口，配合 `git log` 使用。
M6（W-35 手机页 / W-36 webhook / W-37 备份 / W-38 多窗口 / W-39 LSP / W-40 定时调度）按用户要求本轮全部不做。

## 约定

- 门禁：`node scripts/run-gates.mjs`（桌面全量 + 样式令牌 + 类型）；触及 package 或 Rust 时用 `--all`。
- 每项 DoD：测试先失败后通过 → 关键断言做一次变异自检并还原 → 8 语言键齐平 → 双语文档同步 → 报告计数一致 → 提交 → push。
- 卡住（需要真实硬件、付费 key、外部账号、人工目视）即转 `blocked` 并写理由，队列继续下一项。
- 禁止：为了绿灯删断言、改 ADR 既有结论、引入新依赖、动 M6 文件。
